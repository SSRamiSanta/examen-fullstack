# Examen Fullstack

Proyecto fullstack monorepo estructurado para desarrollo ágil y escalable.

## Estructura del Proyecto

```text
examen-fullstack/
├── apps/
│   ├── backend/    # API / Servidor (TypeScript, Java, Python, etc.)
│   └── frontend/   # Aplicación Web (React, Next.js, Angular, etc.)
├── packages/       # [Opcional] Librerías y utilidades compartidas (DTOs, validaciones)
├── docs/
│   ├── arquitectura.md  # Justificación del estilo arquitectónico y patrones
│   └── ia.md            # Documentación de gobernanza y uso de IA
└── README.md
```

## Requisitos Previos

- Node.js / Python / Java (según stack seleccionado)
- Gestor de paquetes (npm, pnpm, yarn, etc.)

## Puesta en Marcha

1. Clonar el repositorio.
2. Seguir las instrucciones específicas en cada directorio:
   - Backend: [apps/backend](apps/backend/)
   - Frontend: [apps/frontend](apps/frontend/)
